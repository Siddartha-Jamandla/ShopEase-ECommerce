# ShopNest Ecommerce Asset Pack

This folder contains the visual assets used by the ecommerce website structure.

## Images

| Folder | Files | Suggested use |
|---|---|---|
| `images/logo/` | `shopnest-logo.svg` | Header, footer, favicon source |
| `images/banners/` | `hero-fashion.jpg` | Home page hero/banner |
| `images/categories/` | `fashion.jpg`, `electronics.jpg`, `home-living.jpg`, `beauty.jpg` | Category cards and category listing |
| `images/products/` | `linen-shirt.jpg`, `leather-tote.jpg`, `wireless-headphones.jpg`, `ceramic-vase.jpg`, `skincare-set.jpg` | Product cards, product details, cart recommendations |
| `images/users/` | `default-avatar.svg` | Profile and review avatar fallback |

## Icons

Standalone SVG icons are available in `icons/`: `search.svg`, `user.svg`, `heart.svg`, `cart.svg`, `menu.svg`, and `close.svg`. A combined `icon-sprite.svg` is also included for inline SVG workflows.

Example:

```html
<img src="assets/images/logo/shopnest-logo.svg" alt="ShopNest">
<img src="assets/icons/cart.svg" alt="Cart" width="24" height="24">
<img src="assets/images/products/linen-shirt.jpg" alt="Cream linen shirt">
```

## Brand palette

- Ink: `#111827`
- Purple: `#7c3aed`
- Pink: `#ec4899`
- Soft background: `#faf7f2`

All generated JPG assets are unbranded concept visuals intended for this starter ecommerce UI.
